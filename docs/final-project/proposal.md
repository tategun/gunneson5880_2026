**Is Education Everything?**

## Abstract
This project looks into the relationship between education, income, and employment using 2024 American Community Survey (ACS) data. This project explores if higher levels of education directly correlate with higher income and employment. By directly comparing these different data points, this project hopes to evaluate if education impacts economic stability and career in the modern landscape.


## Overview
The purpose for this project is to take a deeper look into education achievement and the larger scope of completing a college education. This topic is extremely important today, as it shapes the path that many young adults may take in their careers. While college has long been an important part of a professional journey, the landscape of education and career are ever changing. With this project I hope to help answer the question of college and career. For this project I will use the skills I learned over the course of this spring semester to be able to fully explore and present the findings.


For this project I will utilize R studio, Tableau, and QGIS. I will use these web mapping tools to successfully gather, clean, and map my data for use on the web.


For this project I will use TidyCensus and the US Census Bureau for obtaining data.

In order to successfully complete this project I will need to use multiple processes to gather and clean the data. I need to first format the data and clean it so it is in proper wide data format. After this I will use Tableau to create a visually appealing and cohesive design.


Some projects that I am inspired by are works by Tedy Iskandar. Iskandar releases his projects in Tableau Public, and the easy to understand and visually appealing style he achieves is very much an inspiration for my final project.


My biggest challenge for this project will be making a visually appealing map very much like my inspirations. I find a certain challenge when blending graphic design skills and very informative graphs, and I hope to expand this with this project.
